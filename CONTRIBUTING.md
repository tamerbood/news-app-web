# Contributing

Thank you for your interest in improving Mada Alalam.

1. Open an issue describing a bug or proposed improvement before starting substantial work.
2. Fork the repository and create a focused feature branch.
3. Make changes without adding secrets, `.env.local`, generated build artifacts, or proprietary content.
4. Run `npm ci`, `npm run lint`, and `npm run build` where your backend configuration allows.
5. Submit a pull request explaining the change, testing performed, and any screenshots for UI updates.

Be respectful and constructive when reviewing contributions. The maintainer reviews contributions at their discretion.

**Licensing note:** This repository currently has no explicit open-source license. Contact the maintainer about contribution and reuse terms before submitting significant code.
