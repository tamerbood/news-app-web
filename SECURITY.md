# Security policy

If you discover a potential security issue, please **do not** disclose exploit details, tokens, passwords, or personal data in a public issue.

Contact the maintainer privately through their GitHub profile, or use GitHub's private vulnerability reporting feature if enabled for this repository.

Include a concise description, affected component, reproduction steps, and potential impact. Please allow time for investigation before public disclosure.

Never commit `.env.local` or any real API credentials. Rotate any secret that has already been exposed.
